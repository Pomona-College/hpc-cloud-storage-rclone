# Cloud Storage Integration with rclone

Welcome to the Cloud Storage Integration with rclone workshop! This course teaches researchers and students at Pomona College how to seamlessly integrate cloud storage (Box and OneDrive) with high-performance computing systems using rclone, a powerful command-line tool for syncing files with cloud providers.

## What You'll Learn

By the end of this workshop, you will be able to:

- Understand the importance of cloud storage integration with HPC systems
- Set up rclone for both Box (institutional storage) and OneDrive (personal storage) at Pomona College
- Execute basic rclone operations: listing, copying, and organizing files
- Implement syncing workflows for moving data between HPC systems and cloud storage
- Automate and maintain cloud storage connections, including token renewal

## Who Should Take This Workshop?

This workshop is ideal for:

- Pomona College researchers using the Sagehen HPC cluster
- Students working on computational projects that generate large datasets
- Anyone needing to backup or share research results across systems
- Users who want to automate data transfers between HPC and cloud storage

## Prerequisites

You should have:

- A Pomona College NetID and HPC account
- Basic familiarity with the command line (navigating directories, running commands)
- A Pomona College Box account (institutional) or OneDrive account
- SSH access to Sagehen HPC system
- Approximately 2-3 hours for the full workshop

## Workshop Structure

This workshop is divided into 6 episodes:

1. **Why Cloud Storage Integration Matters**: Understand use cases and options
2. **Setting Up rclone with Box at Pomona**: Step-by-step Box configuration
3. **Setting Up rclone with OneDrive at Pomona**: Step-by-step OneDrive configuration
4. **Basic rclone Operations and Commands**: Learn essential rclone syntax and commands
5. **Syncing Workflows: Copy vs Sync**: Advanced data synchronization strategies
6. **Automation and Token Maintenance**: Schedule transfers and maintain connections

## Key Features of This Course

- **Pomona-specific guidance**: Uses actual Sagehen HPC infrastructure and institutional accounts
- **Hands-on examples**: Each episode includes practical challenges with solutions
- **Two cloud storage options**: Covers both Box (institutional) and OneDrive (personal)
- **Real-world workflows**: Examples based on actual research scenarios
- **Token management**: Covers OAuth setup and token renewal procedures
